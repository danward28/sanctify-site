Private by design

Enough context to help. Not a browsing-history product.

No page reading

The local protection client uses the website or domain address needed to recognize a blocked destination. It does not read the page's words, forms, messages, or images.

Five-minute local context

The recent blocked address stays in temporary storage on the device for no more than five minutes so you can choose to report a mistaken block.

Explicit reporting

Routine events use a rotating, non-readable fingerprint. The actual domain is shared only when you select This should not be blocked.

Common questions

Clear before you install.

Where does the Sanctify page appear?

It appears through native Android protection, the Safari protection bundled with the iPhone and iPad app, and Browser Protection for desktop Chrome and Edge.

Does Sanctify read the pages I visit?

No. Browser protection uses the website address to recognize a blocked destination, but it does not read page contents. Routine activity does not retain a readable domain.

Can my faith leader see the blocked website?

No. Shepherds never receive the website address or browsing history. A support message contains only what the family member chooses to type.

What if the website should not have been blocked?

Select This should not be blocked within five minutes. Sanctify receives the domain and the optional note for review. The page stays blocked until the family policy or reviewed list changes.

What happens in an app without the Sanctify page?

The unsafe destination can still be blocked, but the app may show its normal connection message because it cannot display the local Sanctify experience.

Will cancellation break the internet?

No. When protection ends, enrolled resolver credentials move to ordinary pass-through resolution so an old device setup does not strand the household without working internet.
